# Kod.Asistan.v0.1
Kullanıcılara günlük işlerinden(hesaplama, selamlama vb) yardımcı olucak bir dijtal asistan tasarlamak
BAŞLA

Kullanıcıdan veri/girdi al (Örn: Hatalı giriş sayısı veya İşlem yoğunluğu).

EĞER Girdi >= Kritik Eşik Değeri İSE:

Güvenlik / Uyarılma Modunu Aktif Et.

Kullanıcıya "Kritik eşiğe ulaşıldı, işlem kısıtlandı veya yönlendiriliyor." mesajını göster.

Sistem durumunu gün hissesine / günlüğe (log) kaydet.

DEĞİLSE (Girdi < Kritik Eşik Değeri):

İşlemi normal akışında devam ettir.

Kullanıcı isteğini yerine getir (Hesaplama, Selamlama vb.).
